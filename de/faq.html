Fragen

Muss ich mich registrieren?

Nein. Dein Telegram-Konto ist dein Konto. Wenn du möchtest, ergänze Telefon, Name und E-Mail unter My account (Mein Konto) im Bot: Ein vollständiges Profil bekommt 5% Rabatt, sobald die Bezahltarife starten.

Wie kann jemand prüfen, ob ein Bericht echt ist?

Jeder Bericht hat einen QR-Code sowie eine Berichts-ID mit Code. Scanne ihn oder gib beides auf unserer Prüfseite ein, um das von uns ausgestellte Urteil und die Zahlen zu sehen.

Was bedeuten PASS, CAUTION und FAIL?

PASS: Der Edge hat in diesem Test standgehalten. CAUTION: gemischte Ergebnisse oder zu wenig Belege. FAIL: kein Edge oder Daten, denen man nicht trauen kann, etwa Signale, die zukünftige Kerzen nutzen, oder Preise, zu denen nie gehandelt wurde.

Was ist der Konfidenzwert des Tests?

Wie sicher wir sind, dass die Zahlen dem entsprechen, was du in diesem Zeitraum tatsächlich erzielt hättest. Eine sekundengenau geprüfte Trade-Liste liegt nahe 100%; eine auf Kerzen nachgespielte Strategie etwas darunter. Der Bericht nennt alle Gründe. Unter 85% kennzeichnen wir das Ergebnis als nur richtungsweisend.

Was kann ich senden?

Eine Handelshistorie (CSV- oder Excel-Export von einer Börse oder einem Signalkanal), eine Freqtrade-Strategie (.py), ein Pine Script oder eine Forex- / Gold- / Öl-Handelshistorie (ein MetaTrader 5-Export funktioniert direkt). Backtests von MT4 / MT5 Expert-Advisor-Dateien kommen bald.

Wird mein Code veröffentlicht?

Niemals. Bei der Bestellung wählst du, ob das Ergebnis öffentlich (mit dem Namen deines Bots), anonym oder privat sein soll. Gezeigt werden kann nur das Ergebnis, nie der Code.

Führt ihr meinen Code mit meinen API-Keys aus?

Nein. Wir fragen nie nach Börsen-Keys. Code wird zuerst gelesen, und falls er ausgeführt werden muss, läuft er in einer isolierten Umgebung ohne Internetzugang und ohne Keys.

Wie lange dauert es?

Prüfungen von Trade-Historien laufen automatisch und sind meist in wenigen Minuten fertig. Strategie-Backtests dauern je nach Zeitraum einige Stunden bis zwei Tage. Siehe Bearbeitungszeit.

Warum verlieren die meisten Showcase-Bots Geld?

Es sind kostenlose Beispielstrategien, getestet mit Standardeinstellungen. Viele wurden geschrieben, um eine Funktion zu zeigen, nicht um mit echtem Geld zu traden. Genau deshalb ist Testen wichtig, und genau deshalb verdient dein eigener optimierter oder gekaufter Bot einen eigenen Test.

Garantiert ein guter Backtest Gewinne?

Nein. Ein Backtest zeigt, wie sich Regeln in der Vergangenheit verhalten hätten. Märkte ändern sich. Wir berichten ehrlich über die Vergangenheit; die Zukunft sagen wir nicht voraus.

Ich habe eine der Showcase-Strategien geschrieben. Kann ich reagieren?

Ja. Sende bessere Einstellungen über den Bot, und wir testen kostenlos erneut und aktualisieren den Bericht. Eine Entfernung ist möglich, sobald du nachweist, dass die Strategie dir gehört, etwa indem du einen Code von uns in ihr Repository committest. Mehr.

Wie erreiche ich euch?

Message @BacktestStationBot on Telegram. Any message that is not an order reaches a person.
